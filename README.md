# DemoQA Cypress Automation

This is a Cypress automation project created for DemoQA using JavaScript and Page Object Model (POM).

### Covered Flow

- Open DemoQA
- Navigate to Forms → Elements
- Automate Text Box
- Enter and verify form details
- Navigate to Radio Button
- Select Yes and verify the selected option
- Added a sample defect test for reporting

### Tech Used

- Cypress
- JavaScript
- Page Object Model
- Mochawesome Reporter

### Run Tests

Install dependencies:

```bash
npm install
